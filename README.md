# 🌐 Full-Stack Portfolio Website

A responsive full-stack portfolio website built with **HTML, CSS, JavaScript, Node.js, and Express.js**. The project includes a modern portfolio, a visitor analytics system, and an admin dashboard for monitoring visitor activity.

## 🚀 Live Demo

**Portfolio:** https://anmolmishraprojects.onrender.com/

**Admin Dashboard:** https://anmolmishraprojects.onrender.com/admin.html

## ✨ Features

- Responsive Portfolio Website
- Node.js & Express Backend
- Visitor Analytics
- Admin Dashboard
- Browser & Device Detection
- Country Detection
- Visitor Counter
- REST API
- Dark/Light Theme
- GitHub & Render Deployment

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- Express UserAgent
- GeoIP Lite
- JSON File Storage

## 📂 Installation

```bash
git clone https://github.com/AnmolMishra4code/Lets-begin.git
cd Lets-begin
npm install
node server.js
```

Open:

```
http://localhost:3000
```
